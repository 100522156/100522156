# 👋 Hi, I'm Miguel

**Computer Engineering student @ UC3M | Distributed Systems & Machine Learning**

I'm in my 4th year of Computer Engineering at Universidad Carlos III de Madrid. I'm mainly interested in **distributed systems**, **machine learning**, **databases** and **low-level optimization** — I like understanding technology from its foundations.

Some things I've built:
- **Parser & code translator** — grammars and parsers with Flex/Bison, translating to prefix/postfix notation (Lisp, Forth).
- **Distributed client-server system** — concurrent networked system with an RPC server in C, a Python client, and web services via Spyne/Zeep.
- **Banking predictive model** — Random Forest and SVM with hyperparameter optimization, automated preprocessing pipelines and a Streamlit interface.
- **Optimization exercises** — modeling and solving linear programming problems with GLPK/MathProg and Python, from single-objective models to multi-constraint scenarios. [→ repo](https://github.com/100522156/p1_heuristica)
